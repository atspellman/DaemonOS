# DaemonOS

**Elegant logic, daemon bound.**

DaemonOS is a hyper-minimal Linux operating system built on Arch, designed for programmers, digital creatives, and efficiency-maximalists. It’s an adaptive local system that evolves with your habits—powered by custom daemons and focused on privacy, automation, and aesthetic logic.

See the [Full Roadmap](https://daemonos.io/pages/daemonos)

## ⚙️ Core Philosophy

- **Minimalist by Default** – No clutter, just clean tools.
- **Daemon-Driven** – Background services ("daemons") learn from user behavior and adapt the environment accordingly.
- **Privacy-First** – All learning is done locally. Your data stays yours.
- **Designed Rituals** – Custom commands like `ritual` for journaling, `sigil` for environment setup, and `watcher` daemons for passive task support.

## 🔮 Features Roadmap

### Initial Setup
- Custom dotfiles and theming
- Welcome message + first-run ritual
- Markdown-native tools and workflows
- SQLite-based ritual journal CLI
- Beginner guide: **The Grimoire**

### Future Daemons
- `habitd`: tracks common app usage and auto-launches tools based on time of day
- `syncd`: backs up and syncs dotfiles, journal, and projects to encrypted storage
- `sigild`: handles encrypted tokens, aliases, and environment switching
- `summond`: shows a dashboard of current system state, habits, and rituals

## 🗝️ Philosophy Behind the Name

> A daemon is a background process—always present, rarely seen. DaemonOS embraces that concept to give users a calm, adaptive, and logical computing experience.
